# guest_house (Toà khách)

Zone: `gate`.

One hut per person or Zalo group: their repos, connections, schedule, profile, files.

## Apartments

| Apartment | Holds |
|---|---|


Apartments named `<hut_id>` are created at run time: a hut, named by Zalo uid or group id; created on the first message.

## Rules

- Code is moved here step by step (see the migration plan); until then the apartments are empty packages.
- Anything that leaves the zone goes through `lobby/dispatch`.
- Details and access rules: [city.md](../../../../docs/architecture/city.md).
